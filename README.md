# Kharthie Ramakrishnan — Developer Portfolio & AI Engineering Showcase

A modern, high-performance portfolio web application built with **React 18**, **TypeScript**, **Vite**, **Tailwind CSS v4**, and **Framer Motion**. Designed with luxury cyberpunk aesthetics, custom kinetic physics cursor, dynamic animations, and interactive showcases for enterprise full-stack projects, AI expertise, and verified credentials.

---

## 🚀 Key Highlights & Features

- **⚡ Modern Tech Stack**: Powered by Vite + React 18 + TypeScript with strict typing.
- **🎨 Luxury Dark / Light Theme**: Tailwind CSS v4 theming with glassmorphism, glowing ambient lighting, and smooth dark/light mode toggle.
- **🎯 Zero-Lag Kinetic Custom Cursor**: Custom cursor built on hardware-level `useMotionValue` (0ms input latency) with dual-layer kinetic spring physics (`useSpring`), magnetic hover scaling, text I-beam mode, and touch device auto-detection.
- **📜 Professional Credentials Showcase**:
  - Realistic framed digital certificate canvas previews with double security borders, issuer logos, and embossed metallic rosette seals.
  - Interactive issuer filter tabs (*Google Cloud*, *Microsoft Learn*, *Anthropic*, *GUVI Full Stack*) with real-time badge counts.
  - Instant search filter by keyword, title, skill, or credential ID.
  - Direct 1-click verification linking to official issuer authorities.
- **🛣️ Multi-Route Architecture (Wouter)**:
  - `/` — Complete interactive single-page portfolio (Hero, About, Skills, Projects, Experience, AI Expertise, Credentials, Contact).
  - `/certificate` & `/certificates` — Dedicated standalone route featuring the credentials catalog with easy navigation back to the full portfolio.
- **📱 Fully Responsive**: Optimized for all devices from ultra-wide screens to mobile smartphones.
- **💫 Fluid Micro-Interactions**: Framer Motion scroll animations, particle background effects, and interactive feedback.

## 🛠️ Tech Stack

### Core & Framework
- **Framework**: React 18
- **Language**: TypeScript (strict typing)
- **Bundler**: Vite 5
- **Routing**: Wouter

### Styling & Animation
- **Styling**: Tailwind CSS v4 with `@tailwindcss/typography`
- **Animations**: Framer Motion 12
- **UI Components**: Radix UI Primitives, Lucide React, React Icons

### State & Utilities
- **State & Data Fetching**: TanStack React Query
- **Notifications**: Radix Toast / Sonner
- **Form Handling**: React Hook Form + Zod

## ⚡ Getting Started

### Prerequisites
- **Node.js** (v18.0.0 or higher recommended)
- **npm** or **yarn** / **pnpm**

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/kharthie/port.git
   cd port
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

## 🔨 Available Scripts

| Command | Description |
